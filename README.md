# TMA3084 Menu App — Bean & Bloom

A Flutter-based coffee shop menu application developed for the TMA3084 Software Engineering Lab.

## Features
- Browse coffee and tea menu items.
- View product images, descriptions, and prices.
- Filter menu items by category.
- Search for drinks.
- Add and view favourite drinks.
- Navigate between the menu, favourites, and profile sections.

## Technologies
- Flutter
- Dart
- Material Design

## Continuous Integration
GitHub Actions is configured to check code formatting, analyze the Flutter code, and run automated tests.
